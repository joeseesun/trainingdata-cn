《人类点击数据是个 bug：前推特 CEO 要给 AI agent 重造一个搜索网络》

一个典型的搜索 agent，回答你一句话之前，会在后台跑 5 到 20 次搜索。在 ChatGPT 里把推理档位调高一档，每次提问它会做 5 到 10 次搜索；再往上调，就是几百上千次。

三年前，帕拉格·阿格拉瓦尔（Parag Agrawal）一天用谷歌二三十次。现在，他名下各种 agent 每天跑掉的搜索量，他自己估算超过当年的一千倍。

这个人的履历不需要多介绍。2021 年 11 月，杰克·多西把推特 CEO 的位置交给他；十一个月后马斯克完成收购，他离开。2023 年，他创办 Parallel Web Systems，做的事一句话能说完：让 AI agent 更好地搜索和使用网页。他下注的起点是一个判断，agent 使用网络的频次，会比人类多出一千倍，支撑搜索的技术和商业模式都得重造。

红杉资本的播客 Training Data 最近请到了他，跟主持人索尼娅·黄（Sonya Huang）和安德鲁·里德（Andrew Reed）聊了五十多分钟。这期节目讲清楚了三件事：一家初创公司凭什么敢碰巨头的生意；为什么他说人类点击数据是个 bug；以及当 agent 替人类上网，互联网延续二十多年的广告生意会怎么塌，又该怎么重建。

搜索的本质，是一道千亿对千亿的配对题

先补一点背景。搜索引擎做的事分三步：爬虫把全网网页找出来读一遍，整理成索引；查询进来，先理解问题，再从索引里检索；然后一层层排序收窄，从几千亿个网页里挑出五个、十个，理想情况下一个结果。

阿格拉瓦尔给了一个很干净的定义：

「这本质上是一个千亿对千亿的配对问题。网页有几千亿个，查询随时间累积也有几千亿个，你要做的就是在两堆东西之间做匹配。」

索尼娅问出了所有人心里的疑问：全网规模的抓取和索引，长期只有谷歌和必应做成过，基础设施又贵，一家年轻公司凭什么碰？

他的回答分两层。第一层，旧搜索的护城河之一是反馈信号。判断哪条结果更好，需要大规模人工评分和点击数据，初创公司两样都拿不到。现在大模型把评分的成本打下来了，专家级的判断可以廉价生成。第二层，基础设施不用一次砸钱建完，可以跟着客户一起长大，客户越多，索引越大越精细。

中间他还聊到一个细节：创业这几年，他在刻意「忘掉」推特的经验。推特是产品市场匹配之后的公司，几亿用户每天用三十多分钟，反馈循环来自海量真实使用。Parallel 完全相反，赌的是几年后才会大规模出现的客户，团队每周都在重新学习。用他的话说，是给「还没到来的客户」建技术。

先抢外包人力的生意，再跟搜索引擎掰手腕

Parallel 第一个产品是个搜索 agent，甚至都算不上传统意义的搜索。查询来了再去现场爬网页。深度研究类任务，用户有一分钟到十分钟的耐心，足够爬很多页面，只要有一张「地图」知道该优先爬什么。

这里有个关键认知：索引本质上是延迟优化。放弃延迟这个维度，就能用现场爬取弥补索引的不足。索尼娅总结成一句话：用推理时的算力，换爬取的时间。所以他们的第一个对手选得很聪明：

「第一天就跟搜索引擎正面竞争太难了，但跟坐在搜索引擎前面干活的人类竞争，容易多了。」

早期客户清单全是原来靠人力整理网页数据的活：保险承保和理赔流程、销售数据补全、金融团队把数据打包寄给外包团队人工清洗再喂给建模。Parallel 接下这些活，真正想要的是副产品：真实工作里的评估数据。用真实用例搞清楚 agent 的搜索该长什么样，比造理论评测集靠谱。

增长逻辑也藏在里面。他举了个例子：一家机构给一万家小微企业放了贷，每月靠人工流程扫一遍网页数据评估风险。换成 agent，每周跑一次，每次触发几十万到上百万次搜索。一个开发者写一段程序，搜索量的放大倍数就是十万级到百万级。

产品节奏上，他们把公司押在三个维度：质量、成本、延迟。前两年主动放弃延迟，只死磕前两个，因为把大模型蒸馏成小模型是相对成熟的工程，未知的研究成分少。等每个价位段都做到质量最好，再回头攻延迟。上周发布的 Turbo，把「从上万亿网页里挑出一千个 token」的读时计算从 3 秒压到 200 毫秒，他自称是市面上明显最快、质量最高的 agent 网络搜索。

人类点击数据是个 bug

整期节目最挑衅的一句话在这：

「在 Parallel，我们的观点是，人类点击数据是个 bug。用搜索干活的 agent，应该依赖 agent 反馈，而非人类反馈。」

逻辑不难拆。人类搜索行为本身就被惰性扭曲了，能打十个字，偏打两个残缺词加一个错别字，指望搜索引擎猜中意图，点击数据记录的全是这种惰性。Agent 的查询更长、更明确、错别字更少，搜索引擎要猜的东西更少。拿人类点击数据训练「给 agent 用的搜索」，信号源从根上就错了。

另一层底气是，大模型擅长压缩信息，学界这些年积累的建模研究可以直接搬到索引和排序上。这是他们敢用模型方法重做搜索的前提。

顺带回应了一个身份问题。安德鲁问，Parallel 有一堆 AI 研究者，按某些定义算不算一个新型模型实验室。阿格拉瓦尔否了：「模型实验室的产出是模型，我们的产出是模型的互补品。」别人发布更强的模型，实验室要多爬一座更高的山；对 Parallel 来说，更强的模型等于多解锁几个用例。他们不做超大规模预训练，方向相反，把大模型压缩成很小的排序模型。

他把搜索任务抽象成一句话：「从上万亿个网页里，给我挑出一千个 token，而且必须是对的那一千个。」整个系统围绕这句话，在内存层级里组织信息，训练挑 token 的模型，在有限的算力和延迟预算里榨出最好的输出。

至于「搜索这么核心，模型公司迟早自己做」的流行判断，他的回应很具体。预训练用的爬取对建新鲜索引没什么用，模型公司没耐心等那些加载极慢的随机 JavaScript，同样的算力换到的 token 少一到两个数量级，不划算。Parallel 是完事主义者，愿意为这些 token 付额外成本。但搜索确实是九成 LLM 用例的刚需，模型公司可以建，也可以买。节目当天，Parallel 宣布了和谷歌云的合作：在 GCP 上给 Gemini 系模型做 grounding，可选的搜索提供商有两个，谷歌搜索和 Parallel 搜索。搜索引擎之王把对手接进了自家企业 API。

人类懒得打字，agent 不惯着你

人类和 agent 用搜索的方式差得很远。人类靠关键词，两三个词加个错别字，剩下的靠搜索引擎猜。安德鲁问为什么，阿格拉瓦尔的回答是：「我们能记住很多词，我们就是懒。」Agent 恰恰相反，查询更长、更完整、错别字更少，搜索引擎不用猜那么多。

这段对话里最有意思的部分，是他对「SEO 垃圾页」的拆解。安德鲁抱怨，谷歌搜「什么产品最好」，排前面的全是带货软文，人类一眼能识破，agent 怎么办？

阿格拉瓦尔从源头讲起。你查一家上市公司最新的营收数字，权威来源是 SEC 的备案文件，那个数字可能躺在 PDF 第 73 页。假如谷歌把权威文件排第一，PDF 加载要 3.5 秒，你还得自己翻到第 77 页。人类懒得干这个。于是网上长出一整类中间页：加载快、关键信息放首屏、99.99% 正确，从 300 页财报里挑出 20 条最该看的数据放在最上面。你可以叫它垃圾，也可以叫它「成功服务了懒惰人类的 SEO」。

关键在于，这个权衡是人类浏览器时代的产物，agent 可以绕开它。Agent 不用点来点去下载 PDF，直接把最权威来源里的相关段落取出来，放进模型上下文。中间页存在的理由，跟着消失了。

效果有数字。用 Parallel 搜索替换普通搜索，agent 的 token 用量能降到一半以下，端到端更快更准。省下的上下文空间，意味着同样的模型能干更难的问题。他把这一切归结为跨层的算力分配：模型层、agent 层、搜索层，每一层都在质量、成本、延迟之间做交易，跟模型行业「先榨出智能，再蒸馏到十分之一成本」的循环一模一样。

索尼娅问他质量的天花板在哪。他的回答是，这道配对题永远做不完，真正的问题是什么时候继续优化的收益盖不过成本。但他赌到不了那一天：模型越来越强、越来越便宜，信息匹配做得比别人好 20%，就是实打实的优势，没理由不做。

互联网的钱包瘪了，他搬出博弈论

阿格拉瓦尔在推特做过广告系统，他说自己「智识上热爱广告」，因为广告让搜索和推特免费，让全网大量内容免费。广告模式高效的核心是差异化定价：谷歌大部分查询是亏钱的，靠一部分查询赚回来，利润率高得惊人。索尼娅自称爱广告爱购物，说自己在给所有人的免费信息做补贴，他接得很快：「你在补贴我们所有人，谢谢。」

Agent 一来，这套逻辑断了。Agent 不看广告，不点广告。索尼娅补了一句：那次访问没法变现。内容方的选择肉眼可见，既然 agent 访问带不来收入，干脆屏蔽 agent，继续花钱做面向人类的 SEO。可 agent 本质上是替人类跑腿的，生意却对不上账。

订阅生意也一样：一千个人类访客转化二十个订阅者，这个漏斗是清楚的；agent 访客会不会订阅，没人有数据，只能眼睁睁看着内容被「无名 agent」拿走。

目前内容方唯一的变现选项，是头部玩家跟实验室签固定费用打包协议，覆盖训练、责任豁免和推理期访问。阿格拉瓦尔认为这个模式本身也是坏的：AI 推理用量今年涨 7 倍、明年再涨 7 倍，两年累计接近 50 倍，协议金额不会跟着涨，没有哪个签约方相信续约时自己的份额不会大幅缩水。固定价格合同，撞上指数增长的用量，续约那天就是矛盾爆发的那天。他在推特卖过数据给 OpenAI，两边都待过，看得清楚。

他的解法，是把广告系统里学到的差异化定价搬过来，两个维度同时差异化：内容越独特稀缺，单价越高；用内容干的事越值钱，单价越高。同一份数据，投行分析师读，就比他退休的老父亲读收更多钱。而且要可扩展，靠模型自动算，别靠一单一单谈。

这里就到了全场最极客的部分：Shapley 值。这是个博弈论概念，三个人协作做出一块比各自单干加起来更大的蛋糕，怎么分才能让每个人都愿意继续合作。机器学习里算特征重要性的 SHAP 值，用的就是它。

问题是，严格计算 Shapley 值需要模拟所有组合场景。他的原话：

「为了算出该给某个内容方一美元，完整的 Shapley 计算可能要花掉好几美元。」

比付出去的钱还多，账算不过来。解法是老三样：造数据、训练模型、做估计。思路是做减法模拟：把某个内容源从语料里拿掉，跑一遍 agent，看输出质量掉多少；再试试多花一分钱算力能不能把质量补回来。能补回来，这个内容源就值大约一分钱。把这种直觉形式化，就是 Shapley 框架；用模型把计算成本压到可承受，就是 Parallel 的工程。他们已经用这套逻辑跟一些内容方谈成了合作。

宏观账他也算了：知识工作花在 LLM 推理上的钱，拿出 2% 到 10% 分给网页数据，这个池子就已经超过今天围墙花园之外所有网页数据生意的总和。按他的测算，agent 网络流量每年涨一个数量级，12 到 24 个月内，这套分配机制就能给大范围内容方带来有意义的收入。

一个彩蛋：公司注册时的名字就叫 Shapley Inc.，当时 shapley.ai 还能注册，shapley.com 是个停放的域名。他觉得这名字对 B2B 产品太糟糕，参会胸牌上一直写着 NewCo，拖了六到八个月才定下 Parallel。理由之一是当时他们确实什么都在并行干，之二是他们预见到会出现一个给 agent 用的「平行网络」：同一篇内容，人类一个读法，agent 一个读法，双受众双发布。

插一个数据点。Cloudflare 监测全网流量发现，AI 相关的页面读取量已经跟人类流量相当。但阿格拉瓦尔提醒，agent 查询量超过人类查询量这件事还没发生，现在还非常早期，出了硅谷这个圈子，很多人连这些新词都没听过。安德鲁补了个观察：财报电话会记录这种内容，通过 agent 消费的人，大概率已经超过听音频和读原文的人，这些高价值网页其实已经翻转成 agent 优先。阿格拉瓦尔说他们自己就是这样，API 文档的第一读者是 agent，文档质量就用 agent 来测。

从「拉」到「推」，以及明天就能做的事

他把这个旅程分成三层。第一层，agent 把网络当工具用，给模型配上人类熟悉的搜索工具，现在绝大多数产品还在这里。第二层，多 agent 系统，子 agent 互相唤醒、编排任务，编码工具里的 subagent 是大家最熟悉的形态，AI 科学家那种长时间运行、往难题上砸大量算力和数据的系统也开始出现。

第三层跟网络直接相关：网络会从「拉」变成「推」。今天不管是调工具还是调子 agent，逻辑都是「我现在要这个，去帮我找」。两三年后会变成「一旦发生这件事，打给我」。触发源是一堆信息流：网页上变化了什么、卫星图像里出现了什么、客户给了什么新反馈、某个 agent 跑完了计算、某个人类有了新洞见。

他给团队常讲一句话：

「只要一件事今天能做、值得做、而且还有 GPU 可用，我们就直接做掉。明天的工作，是对世界变化做出的反应。」

对 Parallel 来说，这些信息流里最重要的一条，就是全网所有变化的东西。到那时，他们是在替所有客户，把算力持续分配到整个网络上。而他对自己那几十个后台 agent 的态度也很实在：扩张边界只有一个，价值对花费。他承认自己现在可能花多了，但不多，懒得管。

最后收个尾，这期节目听完，有几件事明天就能做：

  • 写文档、发内容的人，把 agent 当第一读者。Parallel 自己的 API 文档就用 agent 来测。检查你的产品文档、帮助中心和公告，结构化、可引用，关键数字别藏在图片和 PDF 深处。
  • 做 AI 产品的人，把搜索当优化变量。换用为 agent 优化的搜索，token 用量能降一半以上，省下的上下文能干更难的活。设计系统时先想清楚质量、成本、延迟三个维度舍哪个，Parallel 前两年舍的是延迟。
  • 内容方和媒体，别急着签固定价格的打包协议。推理用量指数增长，固定合同在续约时必然吃亏，关注按价值和用量计费的分配机制，按他的测算，窗口期是 12 到 24 个月。
  • 普通用户，从一个每周自动执行的监控任务开始，盯竞品价格、盯政策更新、盯自己的品牌提及，让 agent 每周跑一次并汇总成行动清单。成本不高，先跑起来再谈优化。
