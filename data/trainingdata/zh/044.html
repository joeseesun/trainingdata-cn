《14 个人起家，5 亿人每周在用：奥特曼把 OpenAI 的底牌讲透了》

2016 年，英伟达创始人黄仁勋亲手把全球第一台 DGX-1 送进 OpenAI 的办公室。那台机器七十磅上下，一个人还搬得动。当时全公司 14 个人，围着白板讨论该干什么，连像样的计划都没有，先定了几个练手项目：让 AI 打电子游戏，训练一只机械手。

九年之后，ChatGPT 每周活跃用户超过 5 亿，公司刚官宣 400 亿美元融资，估值约 3000 亿美元。2025 年 5 月，奥特曼第三次来到红杉的 AI Ascent 大会，一开口就说：这里是我们最早的办公室，回来感觉真好。他还感慨，现在的机柜依旧巨大，可那台老机器如今看着小得惊人。

这场对谈由红杉合伙人帕特·格雷迪和阿尔弗雷德·林主持，台下坐满创业者。奥特曼讲了 ChatGPT 怎么被撞出来，OpenAI 要拿哪块地盘，还给出一张 2025 到 2027 的时间表。干货很多，按主题拆开看。

GPT-3 的 API 上线时，世界没在乎

回到 2016 年。奥特曼的原话是，那时的 OpenAI 是一家有强烈信念和方向的研究实验室，但没有行动计划。LLM 这个概念当时还很遥远，团队先做项目验证自己：打电子游戏、开机械手。后来有人对无监督学习和语言模型来了兴致，一路做到 GPT-1、GPT-2。

Alfred 林打趣问，现在还在打电子游戏吗？奥特曼答：那个我们已经很擅长了。

GPT-2 开放过模型权重，外界没什么反应。到 GPT-3，团队觉得手里有点东西了，麻烦也来了：想不出它能干什么，继续放大还需要天量资金。奥特曼说，他们正进入十亿美元级模型的时代，这种事没法当成纯科学实验来做，除非你是粒子加速器。

于是有了 API。很多人以为 ChatGPT 是 OpenAI 第一个消费级产品，奥特曼当场纠正：第一个产品是 API，第一个消费级产品是 DALL-E，ChatGPT 排在后面。做 API 的逻辑来自他当 YC 总裁时的观察：做 API 的公司，上行空间通常能打开；把东西做得更易用，通常有巨大收益。自己想不出该做什么产品，那就写好软件把模型跑稳，让别人去找应用。说白了，API 就是给发电机装插座，电是现成的，能不能用看接口。

2020 年 6 月，GPT-3 进了 API。

「世界没在乎，但硅谷在乎了。」

奥特曼回忆，当时几乎没有来自主流世界的关注，一些创业者却激动地说这就是 AGI。真正靠 GPT-3 API 做成生意的，他记得只有几家文案代写公司，那是 GPT-3 唯一越过经济门槛的用途。

但有个细节埋下了 ChatGPT 的种子：大家在 Playground 里就是爱跟它聊天。模型当时根本不会聊天，RLHF（基于人类反馈的强化学习）还没做，体验很差，人们照样聊得停不下来。奥特曼说，这是 API 产品唯一跑出来的杀手级用法，直接催生了后来的 ChatGPT。

到 GPT-3.5，能做成生意的品类从 1 个涨到 8 个左右，团队对「人就是想跟模型说话」的判断越来越强。2022 年 11 月 30 日，ChatGPT 上线，距公司成立六年。今天，每周有超过 5 亿人跟它说话。

公司变大的陷阱：人多了，事必须多更多

Alfred 林先夸了一句，过去半年 OpenAI 发版速度肉眼可见地变快。他问，怎么让一家大公司越跑越快？

奥特曼给了一个很具体的诊断：很多公司犯的错，是变大之后做的事情没有变多。人变多了，产品还是那么多，公司这锅糖浆就开始凝固。

他的解法：让每个人都忙起来，团队要小，做的事要远多于人头数。否则就是每个会挤 40 个人，为一小块产品地盘吵半天。他引用一句老生意经，好的高管一定是忙的高管，闲人扎堆只会空转。

在他看来，研究者、工程师、产品人几乎贡献了公司全部价值，要让这些人忙且高产出。OpenAI 的做法是让相对少的人扛巨大的责任，而让这件事成立的前提，是事情必须足够多。

他们也确实不得不多做。奥特曼说，现在的机会是去做一个真正重要的互联网平台：做每个人跨服务、跨人生场景的个性化 AI，主品类加长尾品类，要建的东西太多了。

摊牌：核心 AI 订阅归 OpenAI，其他留给你们

台下有创业者直接问：我们怎么避开你的碾压？奥特曼的回应等于把牌摊在桌上：OpenAI 要做每个人的核心 AI 订阅，就是这期节目标题里那句 core AI subscription for your life。

具体分三层：最底下是越来越聪明的模型；中间是几个关键入口，包括未来的设备和类似操作系统的东西；最上面才是 ChatGPT 里的体验。至于真正的平台化，API 和 SDK 该长什么样，他说还没想清楚，可能会试错几次，但一定会做出来，希望它能在世界上催生难以置信的财富创造。

Alfred 林替听众总结：别去做核心 AI 订阅，其他都能干。奥特曼补了一句：你要是能做出比我们更好的核心 AI 订阅，请便，那很棒。

融资的事，Alfred 林提到传闻里的 400 亿美元，奥特曼回应已经官宣。至于野心，他的回答出人意料地朴素：做出好模型，发好产品，除此之外没有总体规划。他们引以为傲的一点，是随世界调整战术的敏捷。

「我听过不少人讲他们的宏大战略，从终点倒推回来，先统治世界，再往前推每一步该干什么。我从没见过这些人真正大规模成功过。」

他信奉往前走，走一步看一步，手头的事先做好。确定要做的只有几件：建海量的 AI 基础设施，把 AI 工厂的产能铺起来；持续把模型变聪明；做好顶层的消费级产品。明年要发什么产品，现在可能都还没想。他说，自己从未对研究路线图这么乐观过。Alfred 林追问路线图上到底有什么，他答：更聪明的模型。全场笑。

有听众问 API 十年后还在不在。奥特曼说，他希望一切最终合并成一件事：用 OpenAI 账号登录其他服务，其他服务通过 SDK 接管 ChatGPT 的界面。你的个性化 AI 认识你、存着你的信息、知道你愿意分享什么，你该能在所有地方调用它。现在的 API 离这个愿景还很远，但能走到。

再往远看，他期待一个 HTTP 级别的新协议：服务联邦化，拆成更小的组件，Agent 之间互相暴露和调用工具，认证、支付、数据传输内建在所有人都信任的那一层。用他的话说，这东西正从雾里走出来，具体长什么样还不确定，大概要迭代几次。

代际断层：大学生把它当操作系统，35 岁的人拿它当谷歌

台下问大公司转型 AI 原生到底错在哪。奥特曼说，每次重大技术革命都这样，没什么新鲜的：人和组织都会死死卡在自己的旧习惯里。他举了个例子，技术每季度变一次，你的信息安全委员会一年才开一次会，决定允许哪些应用、数据能不能进系统，看着都疼。

他的预测：大公司还会再挣扎两年，假装这一切不会重塑所有东西，然后突然投降，最后一刻慌乱补课，但已经晚了。创业公司会直接从他们身上碾过去。

这种断层在个人身上更明显，公司只是同一个症状。他给现场的人出了个题：找一个普通 20 岁的年轻人，看对方怎么用 ChatGPT，再找一个普通 35 岁的人，差距大得难以置信。他拿智能手机类比，当年每个孩子上手就会，长辈花三年才学会基本操作。

年轻人的用法已经系统化了：复杂的配置，接一堆文件，常用提示词背在脑子里或存在备忘录里随时粘贴。更关键的是，他们做人生决定之前会先问 ChatGPT，模型里有他们生活里每个人的完整上下文。奥特曼说，记忆功能是个真正的转折点。

「粗暴地概括一下：年纪大的人把 ChatGPT 当谷歌替代品，二三十岁的人拿它当人生顾问，大学生把它当操作系统。」

那 OpenAI 内部呢？Alfred 林问公司多少代码是 AI 写的，奥特曼说不知道具体数字，按代码行数衡量是件蠢事，微软那个 20% 到 30% 的说法他也觉得没意义。他给了一个更狠的表述：AI 在写有分量的代码，写的是真正要紧的那些部分。

编程是中枢，语音催生新品类，理想态是一万亿 token 上下文

有人问编程在 OpenAI 的版图里算不算一个垂直应用。奥特曼说，编程比垂直应用核心得多。现在你问 ChatGPT 一个问题，得到一段文字或一张图；未来你该得到一整个程序，每次回答都配上定制渲染的代码。写代码是模型撬动现实的方式，调 API、让事情在世界上真实发生。ChatGPT 应该极其擅长写代码。从助手到 Agent 再到应用，他说这个过程会感觉是连续的。

语音被排在极高优先级。奥特曼承认，OpenAI 还没做出足够好的语音产品，就像当年文字模型也磨了很久。现有语音模式最有趣的发现，是它在触屏之外叠加了一条并行通道，你可以一边说话一边点手机。语音加图形界面的组合还没破解，但一旦语音做到真人级，会催生一整类全新设备。

传感器数据也有人问。奥特曼说，大家已经在这么干了，把温度等物理世界的数据塞进 o3 的 API 调用，部分场景效果很好，最新模型处理这类输入比以前强很多，之后会做得更内建。

谈到模型继续变聪明的配方，他给出三样：算法、数据、算力。杠杆最高的还是大的算法突破，剩下的 10 倍级、100 倍级突破不多了，但哪怕还有一两个，也是大事。

怎么管研究团队，他的答案很反主流：需要自上而下协调的项目确实要有个人当四分卫，但大多数人自上而下管得太多了。OpenAI 创立时专门研究过历史上运转良好的实验室长什么样，能给他们提建议的人几乎都已经去世了。他们把那些原则厚脸皮地抄过来用，结果好得惊人。他说，很多人跑来问经验，听完说很好，然后回去按自己的想法干，然后就没干成。

学术界的需求也有人问。奥特曼说，OpenAI 有学术合作项目，但大多数学者要的其实很简单：拿到模型，或者拿到基座模型。九成的力气花在把通用模型整体变好上，定制合作只是零头。

定制化这个问题，他给了一个理想态：一个很小的推理模型，配一万亿 token 的上下文，把你的一生装进去。模型永不重训，权重永不定制，但你这辈子每段对话、每本书、每封邮件、看过的每个东西都在里面，外部数据源全部接上，人生持续追加进上下文，公司数据同理。今天做不到，其他一切方案都是对这个理想的妥协。

时间表与残局：2027 年机器人上场，第 60 天才是真考验

未来 12 个月价值从哪来？奥特曼给了三层：更多的基础设施，更聪明的模型，以及把这些东西接进社会的脚手架。展开到年份：

  • 2025 年，Agent 开始真正干活，编程会是主导品类，另有几个品类跟上。
  • 2026 年，AI 开始发现新东西，可能做出一些重大的科学发现，或强力辅助人类做发现。
  • 2027 年，这一切从智力世界进入物理世界，机器人从新奇玩意变成正经的经济价值创造者。

他补了一句，2027 那条是张口就来的猜测。背后的信念倒是很坚定：人类走出地球、铺开定居之后，可持续的经济增长大部分来自更好的科学知识，以及把它实现到世界里。

被问到 GPT-5 会不会比在场所有人都聪明，他没正面接，只说了一句：如果你觉得自己比 o3 聪明得多，那可能还有点路要走，o3 已经相当聪明了。

最后是给创始人的建议。奥特曼说，挑战会越来越大、赌注越来越高，但情绪消耗会越来越轻，抗压能力是练出来的，每扛过一次就强一分。危机爆发的那个时刻反而好熬，肾上腺素管够，支持的人会围过来，哪怕公司钱烧光倒闭了，也会有人拉你一把。真正难的是事后，第 60 天，肾上腺素退了，人群散了，你一个人收拾残局、重建公司。他提醒，大家都在讨论怎么熬过危机当天，几乎没人讲怎么处理危机之后，而这恰恰是可以刻意练习的部分。

对了，他当时还在陪产假里，特意跑来站台。Alfred 林最后替全场谢了他这一趟。

整场听下来，有几件事明天就能用：

  • 个人用户：学大学生的用法。打开 ChatGPT 的记忆功能，把高频提示词存成模板，接上常用文件和上下文，把它从搜索替代品升级成带完整记忆的助手。做重要决定前，先让它把利弊和盲区过一遍。
  • 创业者：正面战场让给 OpenAI，模型、入口设备、订阅它都要做。应用层、垂直行业、Agent 工具链仍是空地。API 和 SDK 的形态还会变，架构别绑死在现有接口上。
  • 公司管理者：对照两个周期，技术变化按季度走，你的审批流程按年走，这个差距就是创业公司碾过来的路。再数一数人头和项目数的比例，人多了事没多，糖浆就要凝固了。
  • 正在扛事的创始人：危机当天靠肾上腺素就能过，提前写好第 60 天的复原清单，团队、现金流、对外叙事，一样一样来。
