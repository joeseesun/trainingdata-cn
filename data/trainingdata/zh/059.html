《v0 用户破 300 万，Vercel CEO 判断：五年内网页将按需生成》

一家卖云服务和前端工具的公司，增长最快的获客渠道之一，居然是 ChatGPT。

Vercel 最近披露，从 ChatGPT 跳转来注册的用户在指数级增长。旧金山 AI Engineer 大会上，有人专门走到 Vercel 展台说：我知道你们家产品，是 ChatGPT 推荐的。

这段对话出自红杉资本播客 Training Data，嘉宾是 Vercel CEO Guillermo Rauch，Next.js 框架的创造者，开发者体验这个概念的代言人之一。这期聊的是 AI 怎么重塑软件开发，他给未来起了个名字：生成式网页。应用按需为单个用户即时生成，下载安装这件事会慢慢退场。

挑重点讲。

写代码的人，换了一茬

ChatGPT 刚发布时，Vercel 内部注意到一件事：这东西写 React 和 Tailwind 特别熟练。React 是前端主流框架，Tailwind 是当下最流行的样式方案。等于模型一出生就带着这门手艺。

常见反应有两种，无视，或者恐惧。Rauch 选了第三种，all in。他们做了 v0，一个文本生成应用的工具，你说想要什么，它直接把能跑的前端做出来。两年过去，增长用他的原话说叫天文数字：超过 300 万 builder 在用，留存和参与度都很高，财富 10 强企业也在企业版上用。

更关键的变化是人。AI 编程工具吸引来的大批用户，已经超出传统开发者范围：设计师、市场人员，任何有键盘的人。他开了个玩笑：与其在团队聊天软件里闲聊，不如把同样的话说给 v0，还能顺便造出个应用。

成本塌到什么程度？以前创业者融种子轮，钱就是用来做第一个原型的。现在 v0 做的原型直接取代了 pitch deck。主持人 Sonya Huang 说，她刚听了一场 B 轮路演，对方的前端就是 v0 搭的。到今天，路演时拿不出一个能跑的前端，反而罕见。迭代速度也变了，你可以在定下方向前，先做几百个原型。

Vercel 还把底层框架 AI SDK 开了源，最近发布了 v0 模型，邀请创业者去做自己的造站 agent。他们学到的东西，一直在往回还给行业。

品味，是能写进模型的东西

主持人 Pat Grady 问了个好问题：质量这件事，怎么系统化？总不能全凭 taste 吧。

Rauch 的回答从指标讲起。AI 产品的妙处在于反馈回路是自带的。第一个 AI 编程产品 Copilot 靠什么衡量进步？补全建议的采纳率。仪表盘上一个大数字，这周 51%，下周 52%，换个模型再看涨没涨。v0 的信号更多：代码能不能跑，页面渲染对不对，用户有没有把应用部署到真实世界，部署之后有没有人用。

主观的那部分，他叫品味。举了个小例子：在 iOS 上打开网站，Safari 顶栏的颜色应该和页面背景一致。不一致，多数人说不清哪里怪；一致了，画布延伸到整块屏幕，就是舒服。过去要教会所有开发者这个细节，得靠框架升级加文档教育。现在直接写进模型：生成着陆页时，自动做对。

框架时代的核心工作，是把人放进「成功的坑」：你按框架的方式走，性能、安全自动及格。LLM 能把这种保护，从几百万开发者扩展到所有会用自然语言的人。框架有收益递减的一天。他做 Next.js 演讲时，会把流程压成数学题：从建文件夹到第一个组件跑起来，最少几步，多少个字符。现在问题升级了：从想法到上线，最短路径是什么。v0 输入框顶上那行字就是缩影：你想发布什么。

他还替今天入场的人高兴：上一代人有灰头发和血泪教训，新人直接继承全人类攒下的经验，某种意义上是跨越式反超。

补个背景。Vercel 诞生于他自己的痛点：把一个网站上线太痛苦，云要从头配，工具和基础设施难打通，Next.js 就是为解决这个问题发明的。第一章，自动化云，做自动驾驶的基础设施，开发体验是特洛伊木马，用最好的体验把人吸进来。第二章，框架之后的时代，自动化写软件本身。

这期最实用的建议也在这段：做开发者工具，你有两个客户。直接付费的是开发者，但你要一直想着，开发者的用户是谁。卖个「加 10 点幸福值」的功能给开发者很容易，两个季度后他的用户不高兴，这生意就到头了。张力无处不在：把配额改成无限量，开发者会欢呼，但下游所有服务都要面对一个没有边界的东西，这对运营是灾难。他承认早期栽过这种跟头。

他的习惯是每个周末从零开始做点小东西，既给平台做 dogfooding，也逼自己回答：还能删掉什么摩擦。至于信念，他的元信念是别攒太多坚定信念。每次有人说 AI 做不到某事，他都站 AI 那边，因为三个月、六个月、九个月后，情况大概率就变了。

AI 拐点：你的客户，变成了 agent

回看 Vercel 这两年的曲线，Rauch 说最戏剧性的是两件事。第一件，整个用户基数以接近零的成本，同比翻倍。以前积累用户量要好多年，AI 把漏斗顶端直接撑开了。v0 本身全栈跑在 Vercel 上，没开任何后门和特殊通道，他们成了自己平台最较真的客户。

第二件，新用户和老用户不一样。他们对代码长短、API 长什么样，没那么敏感。Rauch 的判断很锋利：LLM 的强项和弱点，会反过来塑造未来的运行时、语言、类型检查器和框架，因为你的客户已经从开发者，换成了他手上的 agent。Stripe 的 API 以优雅著称，现在要多问一句：能不能改点什么，让 LLM 这个「用户」用起来更顺。新用户耐心也更少，出错就想掀桌，这逼着产品把可靠性做到 99.99%。

他还描述了一个错位的时代：底层模型可靠性还很低，AI 供应商隔三差五宕机；消费端的普及速度却前所未有。互联网当年花了很多年才让所有人上网，AI 这边采纳速度直接起飞。基础设施边跑边建，需求端已经爆炸。

公司层面，他发过一条推总结企业的路径：没有 AI，然后组建 AI 原型团队，然后原型变成生产级产品，成立 AI 产品团队，终局是每家公司都变成 AI 公司。客服 AI 是摩擦最低的入口。Vercel 走得更远：先给自己造了个自家技术的专家模型，v0 一鱼两吃，既喂给官网的支持流程，又当成产品卖。10 万多客户想要专业服务，以前只能婉拒，现在卖 AI agent，等于把 CEO 和 CTO 的大脑批发出去。他引用黄仁勋的说法，这是他们业务的 token 工厂，人类放大器。

下一步，连防火墙和可观测性都要用 AI 重做：agent 发现你的服务在报 500 错误，直接提交一个带修复方案的 pull request。离全自动基础设施还有多远？他的回答是，差不多就在眼前了（practically almost there）。录制当天，Google Cloud 和 Cloudflare 刚发生大范围宕机，波及不少 Vercel 客户。Vercel 的基础设施已经能自动检测和修复，把问题喂给 v0，看一遍日志和可观测数据，就能给出精确诊断：问题出在哪，该去找哪家供应商。

回到 ChatGPT 获客，原理其实不神秘。Vercel 做开源 AI SDK（可以理解为 AI 界的 Next.js）时，顺手做了个 playground，让多个模型同题作答，你可以问「可乐和百事哪个好」，看各家模型同时亮观点。他们长期观察各模型的先天偏好：问「部署 React 应用最好的方式是什么」，模型经常选 Vercel，因为训练数据里 Vercel 相关的文章、讨论、GitHub issue 足够多。营销的玩法变了：以前人们靠看播客、读文章认识你，现在直接问自己的 AI 伙伴。另外 AI 回答还要靠搜索做 grounding，内容仍然要做，形态要变：人们不再搜关键词，开始问完整的问题。FAQ 式内容一对一匹配提问，Vercel 按 LLM 优先的方式重新组织对外内容，效果不错。

两类 agent，两类开发者

竞争格局怎么看？Rauch 给了两个框架。

第一个，虚拟同事。设计师、开发者、营销，都会出现虚拟版本。通用问题大家先去 ChatGPT 或 Claude，但反复回来解决同类问题的人，会去找专家 agent。他举了自家客户的例子：OpenEvidence，界面像 ChatGPT，底层接的是前沿医学数据，医生的专用专家；GC AI 做法律，同赛道还有 Harvey；金融领域有 Hebbia 和 Perplexity。世界会有几百万个、甚至几亿个 agent。数字原生公司都得回答一个难受的问题：如果今天重新发明，我的界面大概率是 agentic 的。

agent 又分两种。同步的，问一句答一句，ChatGPT 和 OpenEvidence 属于第一代。异步的，能长时间干活，能和其他 agent、其他人协作，长期看更有意思。v0 在模糊这条边界，你说「给我做个电商最优的界面」，它先做一轮研究再动手。IDE 加 AI 是同步界面，但你可以躺在床上冒出个想法，让 agent 自己去煮，回头交一个 pull request。

第二个框架，前端仍然重要。输出端有产物，网站、PR、一条等你确认的消息；输入端要抓住人的注意力，入口必须符合人体工学。他研究 UI 的结论是，agent 是一种独立模态，很难塞进现有产品里。所以 Vercel 给 v0 单独做了入口 v0.dev。Google 也一样，把 agentic 界面单独叫 AI mode，像 Google Maps 一样是独立产品，用户在入口处挑选自己的战士。

开发者世界也在分裂成两类：造应用的，和造平台的。造应用的最简单，对话式上手；造平台的给模板和起点，但还是得卷起袖子写代码。他用 Waymo 做比喻：v0 是那辆端到端不接管的自动驾驶车，真要接管，有集成让你弹射到 Cursor 或 VS Code；Vercel 平台本身更像以人类专家为中心的驾驶。LLM 越强，v0 这边吃掉的漏斗顶端越多。他自己是 CEO，时间有限，已经很久不用传统编码工具，只用 v0，只关心一件事：从想法到上线的时间。

更多的应用，也会是更好的应用

主持人问了个尖锐问题：人人都在造软件，世界会更好，还是更多噪音？

Rauch 的答案是更好，而且有方法论。团队持续分析客户掉进去的错误类别，问一个问题：模型能不能解决？能解决的写成严格的 eval 塞回产品。Safari 顶栏那个细节，就这么进了几百万人的默认体验。

安全上有个漂亮的案例。Vercel 的 CTO 在一个开源框架里发现漏洞，帮对方在广泛发布前修掉了。他们随即把这个 PR 当考题发给所有前沿编码模型：看出问题了吗？好几个模型答对了。他当时就想，下一步是让 LLM 泡在现有代码库里，烧 token 找漏洞。没过多久新闻应验：Linux 内核一个 use-after-free 漏洞，基本由 OpenAI 的 o3 独立发现。这类漏洞轻则崩溃、拒绝服务，重则数据泄露、远程代码执行。资深内核工程师说，这类问题其实遍地都是，只是专家没带宽。LLM 会写出「构造即安全」的代码，下一个 Heartbleed 不会发生在 AI 写代码的世界。

反方向的证据他也摆得坦白：LLM 会顺手把数据库密钥写进浏览器端代码。v0 到目前为止拦下了几万个这类漏洞，最近一次问内部研究工程师，数字是每天大约一千个，相对于 LLM 原本想直接发布的版本。Vercel 的底气在基础设施原语：生成的代码即时送到服务端，交互部分送客户端，文档里建议人类做的安全动作，平台可以自动驾驶完成。

性能同理。Web 工程的复杂在于它是个 generator，随时间一点点吐内容，落到视网膜上的一切都得在正确的位置。Apple 靠人肉测试文化做到极致，他想把这些交给扎根在生产数据里的 agent，让软件下一代自动变好。

还有 QA agent。他周末试遍了语音转文字品类最火的三个产品，两个死在关键路径上：下载、注册、给系统权限，哪一步都可能挂。创业者当时肯定觉得稳了。亚马逊 CTO 有句名言，everything fails all the time，一切随时都在失效。所以要有机器人一直盯着关键路径：购买、注册、联系销售、下载。

生成式网页：下载安装会输

聊到「一次性应用」，Rauch 的立场很激烈。他一直反对应用是永久物的观念。看看 Mac 上装软件的仪式感：挂载一个 DMG 临时卷，从 Finder 弹出，拖进应用程序文件夹，从此这就是一只你要长期喂养的小狗。他觉得自己是 Team Web，一切应该即时：打开 ChatGPT.com，打开 v0.dev，就完了。

基础设施也在换挡。他的概括：网页从静态到动态，现在进入生成式。Vercel 押了很多年的流式技术，就是 Amazon 商品页那种即时计算推荐的能力，后来长成了 Fluid Compute，正好接住 LLM 流式输出的负载。同时要为一个由 agent 访问的网页做准备：llms.txt 让网站给 agent 一份替代表示，MCP 则让 agent 和 agent 直接对话。

「如果生成在质量、性能、安全和可靠性上持续变好，下载、安装、采购软件这场仗，打不赢。我永远站完全生成式软件这边。」

他自己已经对「找软件」产生生理性反感，因为脑子里知道可以直接生成。黄仁勋说过，未来所有像素都将生成，而非渲染。Rauch 认为网页体验同理。开发者会转而造 agent 和 agentic 平台：要生成应用去 v0，要造平台来 Vercel，v0 可能成为未来互联网的生成引擎，浏览器集成已经在做，随时从现有应用里调用 v0。

时间表他给得很具体：五年内，网页会经历最大的一轮变革，界面、习惯、创作者数量全算上。三年内，王国崩塌，互联网原生的老公司调整不够快，AI 原生公司会以前所未有的速度冲上去。

快问快答里还有几个彩蛋。他最常用的外部 AI 应用是 Superwhisper 和 Wispr Flow 这类语音转文字工具，他从小是「打字最快的孩子」，现在改用嘴了。最敬佩的人是 Karpathy，vibe coding 一词加上语音编程的愿景正在兑现。他推荐过一篇文章，《The Five Whys, and Why the World is About to Get Weirder》，讲空难被研究到极罕见之后，能冒头的都是最离谱的事，从零直接接管世界。被低估的是什么？LLM 本身。这是一次平台转移，需要重连大脑，今天长大的孩子等于自带心灵魔法，他说他嫉妒。

明天就能用上的几件事

这期聊的是未来，有几件事今天就能动手。

  • 内容营销按问题组织。人们开始问完整的问题，FAQ 式内容一对一匹配提问。搜索排名仍然要养，AI 回答还要靠搜索做 grounding。
  • 把关键路径交给 QA agent 盯着。注册、登录、支付、下载，任何一步挂掉都是真金白银的流失。他试的三个语音转文字产品，两个挂在关键路径。
  • 原型别等融资。用 v0 这类工具先做，做一百个再挑一个，路演时带一个能跑的前端。
  • 周末用 AI 从零做个小东西。保持对摩擦的敏感，顺便体验一下今天入场的人手里有什么牌。
  • 问自己一个问题：如果今天从零重新发明我的产品，界面会是 agentic 的吗？答案如果是会，早动手比晚动手便宜。
