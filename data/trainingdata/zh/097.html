《一周 35 万个安卓应用，谷歌 Gemini 负责人把「模型吃掉 Harness」讲透了》

先报一个数：35 万。

这是功能上线一周内，开发者在 Google AI Studio 里造出来的安卓应用数量。谷歌 DeepMind 负责 AI Studio 和 Gemini API 的 Logan Kilpatrick 报出这个数时自己补了一句：这些应用以前大概率不会有人替你开发，因为它们大多是为了解决某个人自己的小问题。

2026 年 6 月 11 日，红杉资本播客 Training Data 请来 Logan，主持人 Sonya Huang，聊了整整一期：智能体、编程大战、世界模型，还有这集标题里那句行话，模型吃掉 Harness（the model eats the harness）。

Logan 是谁？简单说，他是谷歌递给开发者的那扇门。AI Studio 和 Gemini API 都归他管，程序员第一次上手 Gemini，多半从他的产品开始。他怎么看这波智能体浪潮，怎么看应用层的机会，值得认真听。

下面拆开讲。

谷歌 50 个产品，有了第二条主线

今年 Google I/O，Sundar Pichai 开场就把当下定义为「agentic Gemini 时代」。Logan 给了一个内部视角：谷歌大约有 50 个产品，历史上从来没有一条主线能贯穿它们。Gemini 出现后，模型成了第一条主线，所有产品都以某种方式用上 Gemini。

现在第二条主线出现了。Antigravity 的 Agent Harness，正在成为谷歌全线产品共享的智能体底座。Search、Gemini 应用、Cloud、AI Studio 里的智能体功能，跑的是同一套 harness。

Antigravity 不好用一个词概括：有核心 IDE，有网页端的 agent 优先体验，有 CLI，有 SDK。Logan 说这是个生态，设计思路是在开发者所在的地方接住他们。

那 agent harness 和编程 harness 是一回事吗？他的回答有点意思：编程是 agent harness 的特化场景，但编程已经被证明是那个通用的 agent harness。各家产品在同一个底座上做特化，AI Studio 的版本偏 vibe coding，Gemini 应用的版本偏全天候消费级智能体，大概八成的东西是共用的。

整个谷歌的产品矩阵现在有多「智能体」？他给的评级很坦率：爬行阶段。

13 个十亿用户级产品摆在那里，责任重大。普通用户还没准备好让 AI 全权代办，他们想坐在驾驶座上，小心翼翼迈出第一步，搜索就是最典型的例子，得带着用户走，不能一夜之间改掉大家上网的习惯。真正接近「走」的是 Gemini 应用和 Spark 这类全天候常驻智能体，还有 Antigravity：你可以挂着自主编程 agent 去重构操作系统，消耗几十亿 token，替你花掉几千美元。这部分由 GDM 负责探路，其余产品渐进跟进。

顺带一提，未来谷歌会留下 3 个 AI 入口，还是 1 万个？Logan 觉得人类天生喜欢分工明确的产品，点开日历就看到日历，挺好。生成式界面听着酷，认知负担反而更高。生态里产品大概率越来越多，谷歌自己选哪条路，是战略决定。

智能体会吃掉谷歌自己的流量吗

Sonya 问了个尖锐问题：如果 AI 替我回邮件，我还会打开邮箱吗？眼球时长掉了，谷歌怎么面对自我蚕食？

Logan 拿搜索举了个反例。AI 刚学会回答问题时，所有人都觉得这对搜索是负和游戏。结果恰恰相反，人们搜索得更多了，agent 也在搜索，等于同时长出两个增量市场。世界上的人类时间总量有限，这点他承认，但一两年内这事是正和的；三五年后技术更强、产品形态变了，才真正难说。

更有分量的是他对成功指标的重定义。他说经常和 Demis Hassabis 聊这个：谷歌的成功，正在从最大化眼球时长，转向最大化用户成果。把事办成，用户好去过自己的日子，这才算产品成功。

打个比方，以前的互联网产品像健身房，盼着你天天来打卡；现在的方向更像出租车，按你到没到目的地算账，谁也不希望你绕路。

顺着这个逻辑，Sonya 提了个词：agent-led growth，智能体主导的增长。她写代码时全让 agent 做基础设施选型，「用什么数据库我无所谓，你定」。购物将来也这样，广告和价值捕获怎么办？

Logan 的看法是，SEO 和 GEO（生成式引擎优化）高度相关，很多新东西只是旧东西的代理变量，层层叠加着演化，最终的变化大概率比大家想象的温和。

编程大战：从「谷歌赢了」到五五开

Sonya 甩出全场最扎心的问题：她身边的开发者朋友用了很久 Claude，OpenAI 拉响警报之后 Codex 追了上来，现在朋友们五五开用 Claude 和 Codex，用 Gemini 的却没几个，为什么？

Logan 先补了一个背景：去年 12 月 Gemini 3 发布时，外界的叙事还是「谷歌赢了」。然后假期里风向一转，所有人的注意力全跑到了 agent 编程上。叙事翻转的速度，比翻转本身更值得记住。

他承认观察合理，也交了底：谷歌内部把编程团队叫「AI 复仇者联盟」，正在全力推前沿。而且他点破了一个关键认知：没有一个真正做长时程编程任务的产品，就很难做出好的长时程编程模型。这就是谷歌签下 Windsurf 交易、把那批人请过来做出 Antigravity 的原因，你需要那台引擎转起来。Sundar 在 I/O 上展示过谷歌内部 token 消耗的增长曲线。

模型层面的证据是 3.5 Flash：一个 Flash 档的模型，编程能力超过了谷歌发布过的所有 Pro 档模型，而且这些提升全部来自后训练（post-training）。他还提醒了一个容易被忽略的变量：预训练窗口。外部看一家公司「落后」，可能没算上大集群训练排期的时间差，而预训练一直是 DeepMind 的强项。

内部怎么用模型？Logan 的态度很开放：他自己所有模型、所有产品都用，因为不用就感知不到生态真实发生的事。但 Gemini 必须是日常主力，谷歌有 10 万多名工程师在用模型、喂反馈，这个飞轮本该是竞争优势。

至于「足够好的 agentic coding 模型会加速研究进展」这个软起飞循环，他说这事看起来显而易见，也许是自己身在其中喝多了迷魂汤。但产品侧的信号是真的：他的团队用 Antigravity 造移动应用，上线速度会快过谷歌历史上任何团队；Josh 的团队端到端交付 Gemini macOS 应用，也创了谷歌 Mac 应用的交付纪录。模型侧还有人类守着，毕竟没人会「不小心」把一万块 TPU 拿去跑一个没什么意义的任务。

企业端呢？Sonya 说，除了编程，企业里还没见到智能体真正干活的例子。Logan 说这取决于你对「干活」的标准定多高。他特别想看到一个指标被公开测量：agent 一次任务平均跑多久。OpenRouter 在统计全网 token 消耗，能看出世界里的智能总量在涨；任务时长每次新模型发布都会往上跳。各家实验室都在讲「新模型能自主干三天活」，那是极端值，但曲线整体在快速上移。企业今年就会在编程之外感觉到变化。

模型吃掉 Harness，应用层怎么活

这集的标题观点来了。Logan 的原话逻辑是这样：

两年前我们说的模型，就是一组权重，token 进 token 出。现在我们还叫它 Gemini 3.5、叫它 GPT、叫它 Claude，但它已经变成了围绕权重长出来的一整套不断膨胀的系统。

智能体工具调用、托管的搜索和代码执行、跑在容器里的模型、agent harness，全被装进了「模型」这个词。而外部脚手架的宿命是：脚手架总是比模型原生能力领先几步，然后模型把脚手架吃掉，变成原生功能。搜索、代码执行这类外部脚手架还有存在价值，因为不同场景要接不同供应商。但当下最典型的例子就是 agent harness，人人都在喊「得自建 harness，alpha 在 harness 里」。

Logan 的预测很具体：12 个月内，模型会把今天这批 harness 消化掉，能力上游进模型本体，alpha 流向别处。到时候再自研 harness，就像今天给旗舰机装一个手电筒 App。

Sonya 反驳了一个常见理由：应用公司自建 harness，是为了不被单一模型厂商锁定。Logan 的回应是，这个逻辑只在模型能力不足时成立。一个真正的通用模型，理应能适配任何 harness。他甚至提议生态里该有人做一个「Harness Bench」，专门测各家模型适配陌生 harness 的能力。测出来你会发现，模型迟早什么 harness 都能用。

那应用层公司怎么活？Logan 给出了一组看似矛盾、其实都成立的判断：

  • 到处都是机会，比 24 个月前更多。当时大家担心智能体会压缩创业空间，结果完全相反。
  • 模型能力已经跑到产品前面，这个落差（capability overhang）本身就是巨大的 alpha。
  • 模型公司只追通用问题，垂直领域里有领域知识、有客户、有生态的团队，能围着最好的模型实验室跑圈。
  • 专注是创业公司的超能力。谷歌有 50 个产品、13 个十亿用户产品，有义务什么都做，创业公司没有这个包袱。
  • 编程能力帮创业公司抹平了和大公司存量代码库的差距，agentic 是一个全新的产品品类，愿意承担风险的人能赢得同样愿意冒险的用户群。

Omni、那条狗，和锯齿状超智能

世界模型部分，Logan 的核心观点是定义正在变糊。I/O 上发布的 Omni，任何输入、任何输出，Demis 把它称作世界模型。它在架构上和 Genie 那类传统世界模型不同，而传统世界模型出了名的贵、跑不动。Omni 是真正的单一模型，背后没有路由到八个模型。以前谷歌要训练一整套：Gemini 管文本，Lyria 管音乐，Nano Banana 管图像，VEO 管视频，还有一堆音频模型。现在一个模型全包，先上线的是目前质量最好的视频编辑能力，其他能力技术上能用，质量还没到最先进，所以没放开。

他讲了一个现场演示。他和模型团队的 Tulsi 在台上演讲，请台下观众用 Omni 现场改视频：一条狗走上台，跳上 Logan 的腿。改出来的版本里，其他嘉宾低头看到狗，会心一笑，Logan 一边撸狗一边继续讲。这种细节里的分寸感，模型全接住了。

Logan 自己做内容从来不用 AI 代笔，他觉得真实性里有巨大的 alpha。他喜欢 Omni 的点恰好是：它不改你这个人，只改你周围那些本来就不属于你的东西，比如布景和咖啡桌。这比满屏 AI 分身健康多了。

游戏是另一个有意思的切面。去年 10 月他发推说「2025 年底人人都能 vibe code 出电子游戏」，现在他承认接近了，但 3A 大作还早。当时 AI Studio 上 20% 的应用是游戏，现在最大类目变成了金融相关（大概 20%，很多在折腾加密货币），然后是个人效率和生成式媒体。GDM 还在 Kaggle 上搞了游戏竞技场，用游戏当 AGI 进度的探针，毕竟 Demis 当年就是因为游戏才入的行。

普通人什么时候能 vibe code 出一个真正好玩的游戏？他想说就是今年。模型能力已经够，缺的是懂游戏的人把脚手架搭对。短期看，编程 agent 加游戏引擎的组合，比纯世界模型更靠谱，因为世界模型天生开放发散，需要有人给它套上可复用的框架。

Sonya 问他，编程是不是已经到了他以前说的「狭义超智能」。他觉得像，而且 AI 没抢走开发者的能动性，反而把他自己的野心重置了：

以前我脑子里转的想法都够不着，只能想想「那该多好」。现在问题反过来了，我冒出一个想法，第一反应是「我是不是还能做得更大胆一点」。我没法只做个 MVP 了，技术允许我往前多走十步。

他预计接下来会在一个个领域里陆续出现这种「狭义超智能」，下一个大概率是可验证性强的领域：数学、金融、科学。最终我们拿到手的，会是锯齿状的超智能（jagged superintelligence），这里尖那里平，参差不齐。

GDM 内部文化他也聊了几句。Demis 是诺奖级科学家，这种气质渗进了公司文化，他反复看过几遍 Demis 的纪录片《The Thinking Game》，一群聪明人凑一起硬啃问题的打法，今天没变；对比之下，Sam Altman 是顶级商人，OpenAI 就是那种气质。Sergey Brin 回到一线，Noam Shazeer 也回了谷歌，Logan 的形容是：这是一个值得反复回味的时刻。DeepMind 的推特简介写着「谷歌的引擎室」，把 Gemini 部署进十亿用户级产品，全世界只有两家公司会遇到这种问题，谷歌一家就有 13 个。他发推也不用公关层层审批，他的原话是，大公司讲真话很难，魔法经过太多流程会被稀释。

他还引用了《硅谷》剧集里 Gavin Belson 的名台词，「我们不能让别人把世界变好的程度超过我们」，然后自嘲：所有人都在抢着让世界变得更美好，这么一框定，这事一点都不零和。

明天就能用的三件事

这集信息量很大，挑三条明天就能动手的：

  • 做应用的人，把「模型 12 个月内会原生学会」当成默认假设来设计产品。凡是纯靠脚手架堆出来的功能，都按短命资产做预算；真正的护城河往垂直领域知识、客户关系和分发上押。模型公司暂时没做的地方，就是你的窗口期。
  • 写代码的人，把野心调高一档。Logan 自己的体会是，现在做 MVP 都不好意思了，技术允许你多往前走十步。35 万个安卓应用里大多数是解决个人问题的，你那个搁置很久的小需求，今晚就能动手。
  • 关注 agent 任务时长这个指标。Logan 特别想看到 OpenRouter 公布平均 agent 任务时长，每次新模型发布它都在往上跳。判断某个领域的智能体成熟没成熟，别看 demo，看任务能连续跑多久。

最后用 Logan 的那句话收尾：技术存在的意义，是替你把事办成，好让你去过自己的日子。产品如此，工具如此，我们用 AI 的方式，大概也该如此。
