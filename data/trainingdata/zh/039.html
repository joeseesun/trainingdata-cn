《拒绝10亿美金收购的 Replit CEO：比 AGI 更好的终局，是10亿程序员》

公司只有6个人的时候，有人出价5亿到10亿美金收购 Replit，CEO Amjad Masad 拒绝了。那段时间他母亲在约旦确诊癌症，全家回国陪护，理性计算的话，拿钱走人是最优解。他没走。

2025年4月，红杉的播客 Training Data 请来 Masad，单集标题就叫「十亿开发者：比 AGI 更好的终局？」。主持人是红杉投资人 David Cahn，四年前他投了 Replit，Sonya Huang 也参与提问。节目里 Masad 给出了当年拒绝的理由：他想让10亿人成为程序员，这件事还没做完。今天 GitHub 账号大约1亿个，Replit 注册用户4000万，估值早已越过当年的报价，他还觉得公司被低估了。

这期节目密度很高，从约旦网吧讲到 Claude 3.7 的集成坑，从25美分一次的定价讲到「功能性 AGI」。下面按脉络拆开讲。

从100美金开始的硅谷故事

Masad 六岁第一次碰电脑，七岁写出第一个程序，教弟弟学数学。他干得不错，弟弟如今在 Replit 上班。父亲是巴勒斯坦难民，攒钱买了台电脑，每晚抱着厚厚的手册，一个键一个键地敲 DOS 命令。小 Masad 凑过去看，觉得这是一台「可以对话的机器」。Replit 这个名字就来自 REPL，Read-Eval-Print-Loop，人机对话的循环。

十几岁他迷上反恐精英，打比赛能赚钱。他发现网吧全靠纸笔记账，就写了一套客户端加服务器的软件，管账号、计时、防破坏，卖给约旦的网吧，赚到第一桶金。上大学时父亲坚持让他读电气工程，因为约旦工程师协会不认计算机科学，而他父亲恰好是这个协会的副主席。

2011年，他靠 O-1 签证去纽约。安曼机场没人见过这种签证，工作人员认定他必须买返程票，700美金被扣掉五六百。抵达纽约时他兜里剩大约100美金，年薪七八万，房租两千。他先做了 Codecademy 的创始工程师，把编程环境搬进浏览器，后来去了 Facebook。

更早的开源 Replit 有个技术突破。按他的说法，他是第一个把一批编程语言编译成 JavaScript、直接在浏览器里运行的人，用的是当时 Mozilla 的研究项目 Emscripten，还得在浏览器里造一层 Unix 模拟。项目在 Hacker News 上爆火，JavaScript 之父 Brendan Eich 发推感叹，约旦的孩子造出了这东西。但手机一跑就崩，因为要下载数十 MB 的 JavaScript。后来他改做后端执行，手机只当一个瘦客户端。今天 Replit 的 App 不到100MB，是 App Store 里最小的应用之一。这段底子，成了后来一切的地基。

10亿程序员的世界长什么样

Masad 的核心判断是：程序员和普通用户之间那道墙，本来就不该存在，工具的复杂度是人为堆出来的。他年轻时用 Visual Basic，做个带数据库的应用，打包成一个 exe 就能卖。Web 时代来了，复杂度不降反升，新人光配环境就要好几天，还得搞懂 webpack、转译这些黑话。开源世界像个大集市，什么都有，但没人负责把它整理成好用的体验。他引用了那句老话：大教堂与集市。他的答案是，用集市造大教堂。

如果人人都能写软件，公司会变成什么样？Masad 认为今天的公司结构还停留在工业革命的流水线上：产品经理写文档，递给设计师，再递给工程师，最后交给市场。学校也一样，幼儿园、一年级、二年级，一条道走到黑。通才型的软件创造者可以跨过所有环节。销售想到一个拉新点子，自己起一个自动找客户的销售智能体；客户在电话里问能不能支持某个功能，当场用 Replit Agent 做个原型给对方看。他强调，这些全是真实客户的故事。

软件的生产方式也会变。他设想了一个网络化的世界：智能体带着钱包，需要数据库就去买，需要发短信就去买，发布软件后收入沿着整个网络流动，每个服务的搭建者都在赚钱。加密货币和稳定币让机器之间可以互不认识地交易，这套基础设施正在成型。

为什么这事有意义？David Cahn 补了一个宏观视角：社交和电商是门槛最低的领域，所以先被科技化；医疗、教育、工业这些占 GDP 大头的行业，门槛太高，硅谷一直进不去。门槛降下来，这些行业才轮得到被改造。还有一个反常识的数据：软件工程师供给一直在增加，工资却一直涨，背后是工程师创造的价值高于工资。新一批开发者进场，能创造的价值只会更多。

Masad 讲了个更具体的故事。印度有个农村大学生，学计算机专业，家里没有电脑，只有一部 Android 手机。他用 Replit 的手机应用学编程，然后在平台的 bounties（悬赏）板块接活。这个板块的逻辑很简单：平台上有人有时间，有人有钱没时间，一拍即合。美国有个做招聘应用的创业者遇到 bug，在悬赏平台上雇了这个学生。学生修好几个问题，赚到的钱超过全家一年的收入。互联网这台财富机器，第一次对这种人打开了门。今天 Replit 的用户遍布所有国家，中国难一些，但也有用户。

他还提到彼得·蒂尔的一个悖论：互联网本该是伟大的平权工具，结果财富反而更集中地涌向硅谷。原因之一是技术远没有想象中易用。他在 Facebook 改版桌面端照片体验时深有体会：团队做了竖向滚动，自己人很兴奋，A/B 测试数据全跌了。排查半天，产品没问题，问题是大多数桌面用户用的是宽屏、竖向空间极小的上网本，硅谷人手一台 MacBook，根本想不到。

产品由少数地方的人做给全世界用，总会有这种盲区。开发者去中心化之后，本地人会给本地人做产品。还有一个案例值得单独说。Sears Home Services，一家百年老公司，花了六个月、六个月前刚完成 Cobol 迁移，没有 ERP，没用现代 SaaS，直接跳到 Replit 上搭智能体管业务。外勤工人每天早上打开一个 AI 工具，算出当天最优的服务路线。做这个工具的团队全是运营人员，没有工程师。从 Cobol 直接到 Replit，中间几十年的企业软件被整个跳过了。

Agent 是怎么被逼出来的

Masad 对 AI 写代码的判断来得早。2012年他读到一篇论文，On the Naturalness of Software，论证代码在统计上和自然语言差不多，用 N-gram 模型做补全，效果超过传统 IDE 的静态补全。他觉得这就是未来。2015年的种子轮 PPT 里，他模仿马斯克的宏图写了一页：先做爱好者学习网站，攒下人类学习编程的数据，再训练模型，做出比传统工具更强的 AI 工具。此后每年他都试一次机器学习。

GPT-2 让他第一次看到希望，GPT-3 发布时，他形容那是属于他们这批人的 ChatGPT 时刻，ChatGPT 本身更多是 UI 创新。Replit 其实是微软和 OpenAI 之外第一家训练代码模型并开源的创业公司，30亿参数的模型一度做到 SOTA。2022年他发过一条爆款推文串，预言软件智能体会改变编程乃至经济。2023年10月的 TED 演讲里，他又押中了后来所谓的 test-time scaling：成本、速度、精度之间做取舍，想让 agent 干得更准，就多给算力和时间，人来当那个创意引擎。

转折点在2024年6月，Sonnet 3.5 发布。Masad 说它有两个关键特质，其中一个大家很少提：它能一口气写出最多3.2万 token 的连贯代码，而且不偷懒。OpenAI 的模型会偷懒，写到一半给你留一行注释，「此处省略其余代码」。Masad 吐槽：兄弟，我让你写的程序，你问我干什么？有了 Sonnet，agent 可以一次生成接近整个仓库的东西，不用写一个函数就跑一次浏览器测试，那种模式贵到没法用。

上线过程很戏剧。2024年3月他看到团队内部的 demo，知道成了，5月裁员聚焦，全公司压上去。9月5日，他自己的生日，定为上线死线，团队里至少有一个人因为觉得没准备好而离职。第一版确实糙，早期尝鲜者很兴奋，扩散到大众就收获一片失望，12月他们才打磨出自己骄傲的版本。

现在的 Agent V2 数据是这样的：日留存、转化、参与度各提升约50%；新用户用 Agent 做出应用后，部署的可能性翻倍；重度用户是5到6倍。而部署过的用户，留存是没部署的10倍。这是 Replit 最看重的数字，因为从想法到上线，正是它和别的工具拉开距离的地方。

架构上他们也推倒过一次。V1 是多智能体系统，状态机加自研的工具调用协议，因为当时模型会幻觉出根本不存在的工具和参数；还有研究显示，模型号称百万上下文，实际超过3.2万 token，推理能力就在基准测试里暴跌，所以他们花大量精力管理上下文。Anthropic 的 computer use 出来后，他们看出模型为长链路推理做了微调，于是改成单线程架构，简单得多。中间还有个教训：Claude 3.7 发布时，Cursor 集成翻车，用户骂声一片，因为 3.7 更偏 agent，硬塞进一问一答的交互里反而变笨。

Masad 从中总结：为当前模型的能力过度优化，会掉进一个局部最优，而创新者窘境的周期已经从几十年压缩到几个月。柯达发明了数码相机却不敢推出，怕蚕食胶卷业务，这种事现在以月为单位发生。所以 move fast and break things 比以往任何时候都重要，你得接受有时候交付粗糙的体验。

Replit 和 Cursor，根本是两个物种

编程工具市场半年内爆炸，Masad 把它分成两类：Cursor 这类是在 VS Code 上加一层极好的 AI 体验，团队里很多人也在用，但它天然是增量创新；Replit Agent 走的是推倒重来的路。他的目标是「无代码、无运维、无 IT」：不让你配数据库，不让你写迁移脚本。他提到一个被忽视的事实，翻翻云厂商的事故复盘，大多数故障源于配置错误，往往是软件更新了，某个环境变量忘了改。

Replit 为此做了一套事务性的同步系统：你在 Replit 上点回滚，代码、数据库变更、环境变量一起回到过去。用他的寿司比喻，别的工具是单点，想吃什么自己配；Replit 是 omakase，主厨发办，你吃什么主厨定。想自己掌控每个选择的人，他劝你别来。

定价上 Replit 是全场最贵的：Cursor Composer 单次请求约4美分，Replit 要25美分。他解释，做 agent 就得迭代、就得调用一堆工具，成本降不下来。这赶走了一些用户，也换来了更多专业用户。等要冲10亿用户时，他们会用开源模型把成本打下来，先做 Roadster，再做 Model 3。他连「vibe coding」这个词都不太喜欢，觉得它把可能性说便宜了。用 Replit Agent 时你根本没空看代码，你盯的是想法在眼前展开。他的原话是：别写代码，vibe 就行。

功能性 AGI：他不信程序员会消失

硅谷流行一种焦虑：AGI 来了，没人需要工作，全民领基本收入。Masad 的立场相反。他认为 AI 会变得极强，但强在两类事情上：训练数据里大量出现过的，以及能构建出优质强化学习环境的，比如游戏、用 Lean 形式化的数学、可执行的代码。至于提出全新想法、理解极端复杂的世界，目前看不到机器怎么学会。

所以他造了一个词，功能性 AGI：能干很多人类正在干的活，因为训练数据够、有真值可训，但它本质上不具备通用智能，扔进一个全新环境、没有明确反馈时，学不动。各大公司把 AGI 定义成「能在电脑前完成经济价值工作的远程员工」，他觉得会到那一步，但他的反应是：如果我有了一个远程员工，我会再造100个，把脑子里所有想法都实现出来。如果你自认是码农，确实危险；如果你靠理解人们想要什么来创造产品，暂时还换不掉。

一个文本文件管全公司

Masad 的管理方式很土。他在 Replit 内部建了一个文本文件，记下每个人的名字和他期望对方交付的一件事，每周开会挨个过：上周那事做完了吗？没做到，为什么？下周做什么？到今天全公司每个人每周五都写同样的两行，他因此能装下整间公司在做什么，既能钻进一个按钮的细节，也能抽出来看全局。代价是新员工流失率高达20%到30%，跟不上节奏的人在头几个月就会离开。

招人他专挑别人不要的「怪人」。有个18岁的少年 Mason，从圣克鲁兹离家出走，去训练营学编程，训练营全在用 Replit，负责人不断给他发 bug 报告，Masad 说不如把你最好的工程师派来，对方说这孩子很怪但确实是最好的。少年来了，连帮人扶门都不会，妻子兼联合创始人 Haya 抱怨他甩门，Masad 说他满脑子都是代码。

他的招聘建议：去小众社区找人，小众加密项目、小众编程语言的社区里，藏着大量被低估的人才。Replit 自己的年轻员工有16到21岁的，也有从没上过班的独立游戏开发者。和妻子一起创业是另一段故事。两人在约旦同一家公司认识，他是第一个员工，她是第二个，设计师和工程师。拿到美国签证那周他们结婚，他24岁。夫妻创始人当年被 VC 嫌弃，先例只有 Paul Graham 和 Jessica。最大的挑战是下了班还在聊公司的问题，问题越聊越大，两人只好定规矩，规定什么时候不许谈工作。当然，规矩经常被打破。

快问快答里还有几个细节。问他 scaling laws 会不会继续成立，他说会，只是要扩展的东西会一直变；最喜欢的 AI 应用，他每天用 Replit 自己搭小工具，顺带夸了 Manus，说它证明了模型能连贯工作约一小时；最被低估的人，他说是 Replit 总裁 Michele Catasta，代码大模型的早期先驱；最喜欢的书，侯世达的《我是个怪圈》。

明天就能用上的五件事

节目里，Paul Graham 给过 Masad 的一句话被反复提起：

「这是你一辈子的事业吗？如果是，就别为日常的鸡毛蒜皮焦虑。只要不死，一切都能修。」

整理这期内容，有几件事读者明天就能动手：

  • 有想法就把它做完并部署上线。Replit 自己的数据显示，部署过的用户留存高10倍，做完比做一半重要得多，用 Replit Agent、Cursor 或者任何顺手的工具都行。
  • 管团队可以抄那个文本文件：每人每周聚焦一件事，周五全员写「本周完成、下周计划」，两行就够。
  • 招人去竞争少的地方找，小众社区、黑客松获奖者、没履历但有作品的独立开发者。
  • 做 AI 产品的团队，别为当前模型的能力把架构焊死，模型每升级一代，系统可能都得重写，留好推倒重来的余地。
  • 想知道 AI 下一步往哪走，去 X 上刷论文，看到新论文就点进去粗读，这是 Masad 自己的读法。

节目结尾 David Cahn 算了一笔账：4000万用户，只走到目标的4%，还差9亿6000万。Masad 没接话，但这大概就是他拒绝那笔钱时想要的东西：一件值得干20年的事，和一个还没被任何人做出来的未来。
